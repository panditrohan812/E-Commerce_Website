# 🛍️ E-Commerce Website

A modern and responsive **E-Commerce Website** developed using **HTML5, CSS3, JavaScript (ES6), and Bootstrap 5**. The application fetches product data dynamically from the **FakeStore API** and provides a complete shopping experience with product browsing, wishlist management, and shopping cart functionality.

## 🚀 Features

- 🏠 Responsive Home Page
- 🛍️ Browse Products
- 📄 Product Details
- ❤️ Wishlist Management
- 🛒 Shopping Cart
- ➕ Add & Remove Products
- 📱 Fully Responsive Design
- 🌐 FakeStore API Integration
- ⚡ Clean and Interactive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- FakeStore API
